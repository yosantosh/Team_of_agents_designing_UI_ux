# Target_ui example

Place reference images here when you want the design agents to use a visual target.

- `profile_reference.png` is a generated placeholder, not a real product screenshot.
- Supported formats: PNG, JPG/JPEG, WEBP.
- The Target UI Analyst hashes each image, maps it to a screen, extracts layout/components, and records confidence.
- Precedence defaults to `tiered`: target wins layout/composition; design tokens and Android/a11y law win color, type, and accessibility. Conflicts escalate to the Dictator.
- For competitor screenshots: use structure only; replace brand assets, fonts, icons, and copy; run legal/IP review before release.
